# Branding And Theme Work

Read `docs/BRANDING_AND_THEMING.md`.

Precedence:

- Public documents: document override → company branding → organization branding → platform branding.
- Internal app: user preference → organization theme → platform default.

Rules:

- User theme preferences must not alter public offers, PDFs, or emails.
- Use semantic tokens.
- Do not duplicate branding resolver logic across features.
- Public document styling must preserve readability and contrast.
