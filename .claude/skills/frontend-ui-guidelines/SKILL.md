# Frontend UI Guidelines

Read `docs/FRONTEND_GUIDELINES.md` and `docs/BRANDING_AND_THEMING.md`.

Checklist:

- Build mobile-first.
- Use shared UI primitives.
- Use semantic CSS variables.
- Keep page files as composition only.
- Split containers, components, panels, dialogs, store, API client, and types.
- Do not create nested cards or hardcoded business-state colors.
- Run `npm run check:file-size`.
