Summary of what's actually changing:
1. Sidebar — section names + 2 new items (Kunder, Aktivitet) + new "Verktyg" section + Prissättning link + Företag moved to Administration.
2. Topbar — notification bell with badge added between search and CTA.
3. KPI tiles (row 1) — sparkline charts + richer secondary text (goal %, count, trend %) added inside existing tiles. Tiles stay same size.
4. ActionQueue (row 2 left) — "Kritisk / Varning / Normal" text chips added inline with item title. Structure otherwise identical.
5. Pipeline (row 3 left) — 4-stage 2×2 grid → 5-stage horizontal row. "Kontakt" stage added.
6. ProjectHandoff (row 3 center) — 3 generic boxes → 3 column headers (Klar/Pågår/Planerad) with count + value. Project table gets a Status badge column.
7. Activity insight — title "Insikt" → "Insikter" + richer sentence. Cosmetic only.
