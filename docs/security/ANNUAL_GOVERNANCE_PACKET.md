# Annual Governance Packet

Owner: ISMS Manager  
Review cadence: Before each annual governance cycle  
Status: Structured baseline complete

Use this packet to run the annual governance cycle for Kollegan ERP. This combines the annual activities that matter most for ISO/IEC 27001 stage 2 without requiring a separate project plan.

## Annual Scope

Complete:

- internal audit,
- management review,
- review of ISMS scope, supplier set, and current baseline assumptions,
- corrective-action ownership tracking.

## Preparation

1. Open:
   - `docs/security/INTERNAL_AUDIT_PLAYBOOK.md`
   - `docs/security/MANAGEMENT_REVIEW_AGENDA.md`
   - `docs/security/ISMS_SCOPE.md`
   - `docs/security/STATEMENT_OF_APPLICABILITY.md`
   - `docs/security/ANNEX_A_CONTROL_TRACKER.md`
   - `docs/security/AUDIT_EVIDENCE_INDEX.md`
2. Decide the audit/review window and participant set.
3. Gather the current dashboards:
   - `docs/security/READINESS_STATUS.md`
   - `docs/security/OPERATIONAL_CLOSEOUT_STATUS.md`
   - `docs/PLAN_STATUS.md`

## Execution Order

1. Run the internal audit and write the result to `INTERNAL_AUDIT_LOG.md`.
2. Review open findings, nonconformities, and corrective actions.
3. Run the management review and write the result to `MANAGEMENT_REVIEW_LOG.md`.
4. Confirm whether:
   - the ISMS scope still matches reality,
   - the supplier set is still accurate,
   - Annex A baseline links still reflect the systems and vendors in use,
   - the remaining open operational gaps are still truthful.

## Annual Outputs

- Completed internal-audit row.
- Completed management-review row.
- Follow-up actions with owners and due dates where needed.
- Updated readiness dashboards if any open gaps or status lines changed.

## Review Rule

Do not restate "all good" unless the review actually concluded that. If a gap remains open, keep it open and assign an owner instead of soft-closing it in prose.
