# Incident Response Drill Playbook

Owner: ISMS Manager  
Review cadence: Before each drill and after major incident-process changes  
Status: Baseline workflow

Use this playbook to run incident-response drills for the in-scope Kollegan ERP environment. Do not commit secrets, production data extracts, or sensitive forensic material.

## Minimum Drill Scope

Each drill should exercise at least:

- detection and triage,
- severity assignment,
- containment decision-making,
- communication/escalation expectations,
- recovery validation,
- postmortem and corrective-action capture.

## Drill Steps

1. Define the scenario, facilitator, and participants.
2. State the simulated severity and affected asset/process.
3. Walk through detection, escalation, containment, recovery, and communication decisions.
4. Record where evidence, tooling, or ownership was unclear.
5. Capture corrective actions with owners and due dates.
6. Record the completed drill in `INCIDENT_POSTMORTEM_LOG.md`.

## Outputs

- Scenario and severity tested.
- Findings and response gaps.
- Corrective actions with owners and due dates.
- Entry in `INCIDENT_POSTMORTEM_LOG.md`.
