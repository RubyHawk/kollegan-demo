# Security Awareness Playbook

Owner: ISMS Manager  
Review cadence: Before each awareness cycle and after major process changes  
Status: Baseline workflow

Use this playbook to plan and record security awareness or targeted training for in-scope Kollegan ERP work. Keep confidential HR notes and personal data outside the repo when not necessary for evidence.

## Minimum Topics

Awareness cycles should cover at least:

- handling of production data,
- secrets and `.env` protection,
- AI usage boundaries,
- incident reporting expectations,
- change/release hygiene for production-impacting work.

## Steps

1. Define the audience, topic set, owner, and delivery date.
2. Link or prepare the supporting material.
3. Run the awareness session or distribute the training material.
4. Record completion status, gaps, and required follow-up.
5. Enter the completed activity in `SECURITY_AWARENESS_LOG.md`.

## Outputs

- Audience and topic set.
- Completion status.
- Follow-up actions where needed.
- Entry in `SECURITY_AWARENESS_LOG.md`.
