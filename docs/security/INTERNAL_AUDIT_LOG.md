# Internal Audit Log

Owner: ISMS Manager  
Review cadence: At least annually and after major process changes  
Status: Empty register as of 2026-04-24

Use this register for completed internal audits only. Keep detailed evidence in linked notes or tickets when needed, but do not commit sensitive logs or credentials.

## Record Rules

- Add one row per completed internal audit.
- Record the auditor or audit team, the scope reviewed, and the main findings.
- Record nonconformities and corrective actions with owners and due dates.
- Link supporting evidence, notes, or follow-up work items where possible.
- Use `INTERNAL_AUDIT_PLAYBOOK.md` to prepare the audit and define the sampled evidence set.

## Entry Workflow

- Follow `OPERATIONAL_RECORD_ENTRY_STANDARD.md` before editing this log.
- Use `INTERNAL_AUDIT_PLAYBOOK.md` to define the sampled evidence set and audit scope.
- Add a row only after the audit is complete and findings/corrective actions are known.
- If this is the first committed row, change the status line to `Active register; last updated YYYY-MM-DD`.
- After committing the row, remove the matching `Open gap as of ...` row from `AUDIT_EVIDENCE_INDEX.md` and regenerate `READINESS_STATUS.md`, `OPERATIONAL_CLOSEOUT_STATUS.md`, and `PLAN_STATUS.md`.

## Entry Template

Use this row shape for the next completed record:

| YYYY-MM-DD | auditor name | audit scope | findings summary | none / listed nonconformities | corrective actions + owners | YYYY-MM-DD or N/A | ticket / note |
