# Supplier Review Log

Owner: ISMS Manager  
Review cadence: Quarterly and after major supplier changes  
Status: Empty register as of 2026-04-24

Use this register for completed supplier reviews only. Do not commit contracts, secrets, billing data, or sensitive vendor communications.

## Record Rules

- Add one row per completed supplier review cycle or supplier-specific review.
- Record the supplier, scope, reviewed risks, and outcome.
- Record follow-up actions, owners, and due dates when gaps are found.
- Link supporting tickets, PRs, or external review notes when appropriate.
- Use `SUPPLIER_REVIEW_PLAYBOOK.md` to prepare the review set and expected evidence.

## Entry Workflow

- Follow `OPERATIONAL_RECORD_ENTRY_STANDARD.md` before editing this log.
- Use `SUPPLIER_REVIEW_PLAYBOOK.md` to prepare the supplier set and expected evidence.
- Add a row only after the supplier review is complete and outcomes/actions are known.
- If this is the first committed row, change the status line to `Active register; last updated YYYY-MM-DD`.
- After committing the row, remove the matching `Open gap as of ...` row from `AUDIT_EVIDENCE_INDEX.md` and regenerate `READINESS_STATUS.md`, `OPERATIONAL_CLOSEOUT_STATUS.md`, and `PLAN_STATUS.md`.
